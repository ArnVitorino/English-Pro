Erros Críticos em TI e Vendas

Como substituir termos que entregam sotaque por vocabulário corporativo nativo.

💻 TI • "Trabalho com programação"
I work with programming.
I work in software development.
Diga sempre "I work in software development" ou "I'm a software engineer / developer".
📈 Vendas • "Passar a proposta"
I will pass the proposal.
I'll send over the proposal by tomorrow.
No meio comercial, use sempre o phrasal verb nativo "send over" (enviar proposta/contrato).
💻 TI • "Está dando erro"
The code is giving error.
It's throwing an error in production.
Código não "dá" (give) erro. O termo correto é "throw an error" (lançar erro/exceção).
📈 Vendas • "Tem alguma dúvida?"
Do you have any doubt?
Do you have any questions or concerns?
"Doubt" soa como desconfiança. Para clientes use sempre "questions or concerns".
💻 TI • "Subir código / deployar"
I will up the code.
I'll deploy the build to staging.
Nunca traduza "subir o código". O termo profissional universal é o verbo "to deploy" ou "push".
📈 Vendas • "Fechar negócio"
We need to close business.
We're ready to close the deal.
Em vendas corporativas B2B, a expressão de ouro é sempre "close the deal".
